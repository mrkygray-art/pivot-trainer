# SOP-117: Site Credential Handling

Harborline Security Services (fictional). Applies to all field technicians and project managers.

## 1 Purpose

Credentials open customer cameras, recorders, and access control panels. A leaked credential is a security incident for the customer. This SOP covers how credentials are stored, shared, and changed.

## 2 Storing credentials

### 2.1 Use the vault only

All credentials live in the Harborline credential vault. Do not write them on paper, in phone notes, in tickets, or in spreadsheets.

### 2.2 No shared default passwords

Every device must have its factory default password changed during installation. Never leave a default password in place, even for testing.

## 3 Sharing credentials

### 3.1 Need to know

Share a credential only with a technician assigned to that site's open work order. Use the vault's share feature so the access is recorded.

### 3.2 Customers

Customer credentials are given only to an authorized contact on the site record, through the vault's secure link. Never read a password over the phone.

## 4 Changing and revoking

### 4.1 When a technician leaves a project

When a technician is removed from a project, the project manager removes their vault access the same day.

### 4.2 Suspected exposure

If you think a credential was seen or sent to the wrong person, report it to your project manager within 1 hour. The project manager changes the credential and notes the change in the site record.

### 4.3 Scheduled rotation

Recorder and panel admin passwords are rotated every 180 days.
